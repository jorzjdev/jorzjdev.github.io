# Портфолио — Георгий Шипунов

Статический сайт-резюме под GitHub Pages. Без сборки: HTML + CSS + немного JS.

```
index.html          главная (RU по умолчанию, переключатель RU/EN)
dodo/index.html     /dodo — пасхалка с пиццей
assets/styles.css   Material 3, базовая фиолетовая схема
assets/app.js       переключатель языка + мобильное меню
assets/i18n.js      английские строки (русские берутся из разметки)
assets/dodo.css     чёрно-белая тема страницы /dodo
assets/dodo.js      пицца: 8 кусков, один клик = кусок за три укуса
assets/resume.pdf   положить сюда PDF резюме
```

## Публикация

1. Создать репозиторий `<username>.github.io` (сайт на корневом домене)
   или любой другой, например `portfolio` (сайт будет на `/portfolio/`).
2. Скопировать содержимое этой папки в корень репозитория, закоммитить, запушить.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.

Все пути относительные, поэтому сайт работает и в корне домена, и в подпапке.

## Что нужно дописать

- `assets/resume.pdf` — файл резюме (на него ссылаются кнопки «Резюме» и «Скачать PDF»).
- Ссылки LinkedIn / LeetCode: в `index.html` найти `data-link=` и заменить
  `href="#contact"` на настоящий адрес, а текст `[добавить ссылку]` — на подпись.
  Там же убрать `data-i18n="todo"` у этого текста. GitHub уже проставлен.
- Телефон из резюме на сайт намеренно не вынесен: страница публичная и индексируется.

## Язык

По умолчанию язык определяется по браузеру, выбор запоминается в localStorage.
Ссылка `?lang=en` сразу открывает английскую версию.
Русский текст лежит прямо в HTML, поэтому страница читается и без JavaScript.
